# Electronics Kit

A browser game that teaches 7–12 year olds how electrical circuits work by placing components on a
virtual breadboard. It is a TypeScript web app (an installable PWA) hosted on GitHub Pages at
<https://spence.com.au/electronics-kit/>, with no accounts, no backend and no analytics.

Work in progress: the design and milestone plan are in [`docs/design.md`](docs/design.md).

## Development

Needs Node 22+ and pnpm (`corepack enable`).

```sh
pnpm install
pnpm dev          # http://localhost:5173/electronics-kit/
```

See [`CLAUDE.md`](CLAUDE.md) for the checks to run before pushing.
