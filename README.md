# Electronics Kit

A browser game that teaches 7–12 year olds how electrical circuits work by placing components on a
virtual breadboard. It is a TypeScript web app (an installable PWA) hosted on GitHub Pages, with no
accounts, no backend and no analytics.

Work in progress: the design and milestone plan will live in [`docs/design.md`](docs/design.md).
